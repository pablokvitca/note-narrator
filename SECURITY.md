# Security policy

## Reporting a vulnerability

Report security issues by [opening an issue](https://github.com/pablokvitca/note-narrator/issues/new) on this repository. Issues are public, so:

- Describe the problem and its impact, and how to reproduce it.
- Do **not** include API keys, note contents, or other private data. If a key was exposed, revoke it in your ElevenLabs account first.
- If you would rather not describe an exploit in public, open an issue that says you have a security report and leave out the details. It will be handled from there.

## Supported versions

Only the latest release receives fixes. Note Narrator is an early (0.x) project.

## What is in scope

Note Narrator runs inside Obsidian and talks to one external service, ElevenLabs. See [Disclosures in the README](README.md#disclosures) for what it sends and stores. Reports about ElevenLabs or Obsidian themselves belong with those projects.

## Contributions

Pull requests can only be opened by repository collaborators. If you have a fix in mind, describe it in an issue instead.
